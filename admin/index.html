İlk kurulum

Panel, içeriği doğrudan GitHub deposundaki data/*.json dosyalarına yazar. Bunun için depoya yazma izni olan bir erişim anahtarı gerekir. Anahtarı bir kez girersiniz; şifrenizle bu tarayıcıda şifreli olarak saklanır ve sonraki girişlerde yalnızca kullanıcı adı ile şifre istenir.

Anahtarı nasıl alırsınız?
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: yalnızca FK-Mimarl-k deposunu seçin
  3. Permissions → Repository permissions → Contents: Read and write (başka izin gerekmez)
  4. Süreyi 90 gün gibi sınırlı tutun; süresi dolunca yenileyin
Anahtar yalnızca bu tarayıcıda, şifrenizle şifrelenmiş olarak saklanır; GitHub dışında hiçbir yere gönderilmez. Kurulumu her bilgisayarda bir kez yapmanız gerekir.
